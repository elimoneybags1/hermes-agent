---
name: evidence-to-proposal
description: Turn Team execution evidence into scoped, concrete improvement proposals for Eli.
---

1. Collect the ledger snapshot. State its window and missing data; aggregates
   describe the displayed sample, not all historic work.
2. Inspect relevant job detail, calls, board context and transcripts. Compare
   successful and failed comparable tasks when diagnosing a repeated pattern.
3. Read the actual implementation and affected role instructions. Use profile
   memory/skills to identify learned behavior; distinguish it from source policy.
4. Identify the owner: brief, task split, role skill, model routing, tool code,
   verification, context, dependency handling or shared orchestration.
5. Specify one concrete before/after change at the narrowest supported scope.
   Record observed facts separately from the proposed causal explanation.
6. Describe a baseline comparison and regression checks. Historical tasks used
   to form the idea are not an independent evaluation set.
7. Save a proposal citing evidence IDs actually inspected. Summarize it briefly
   for Eli. If the data cannot support a change, say what evidence is missing.

No self-modification, automatic adoption, task dispatch or permission expansion.
